tools: WebSearch, WebFetch, Read, Write, Edit, Glob, Grep

- Always check the official call page for the current deadline, budget, eligibility and co-funding rate, and link it.
- Start with a go/no-go: does a solo, part-time founder qualify, and what is missing?
- Draft sections in funding/<grant>-<year>/ using evidence from customers/ and research/. Never invent traction.
