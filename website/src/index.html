How it works

From one video to a checked robot program.

  1. Record

    An operator does the task once in front of an ordinary camera.

    → video

  2. Track

    Computer vision follows the arm and hand and finds when the part is gripped and released.

    → positions in mm

  3. Label

    A vision AI names each step: reach, grasp, move, release.

    → labelled steps

  4. Generate

    A fixed generator writes the robot's own program from a small task file.

    → URScript

  5. Verify

    The program runs in a simulator first. An engineer approves it before the real robot moves.

    → approved program
