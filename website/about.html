About

Automation for factories that change every week.

Big plants can afford weeks of robot programming for a line that runs for years. Small and high-mix factories cannot. Robotonic exists to make teaching a cobot as quick as showing a colleague how the job is done.

Purpose

Make cobots worth it for small batches

When a new task takes hours to teach instead of days, automating short runs starts to pay back.

Belief

The operator is the expert

The best description of a task is the person doing it. We capture that skill and keep them in the loop.

Goal

Hours to deploy a task

The one number we work on: the time from "we want this automated" to a running program.

Roadmap

From a service to software anyone can use.

We start by doing the work ourselves, so every task teaches the software something. When one task family runs with little hand-tuning, it becomes a product.

  1. Now

    Fixed-price service

    We set up new tasks for integrators and factories in a week, using our own tools.

  2. Next

    Software for integrators

    Integrators record, generate and verify programs themselves, with our support.

  3. Later

    Teaching platform

    A subscription service: film a task, get a verified program for the robot brand you run.

How we work

Principles.

Honest

We show where we stand

No made-up numbers or logos. If something only works in simulation, we say so.

Open

Built on open tools

We build on open-source robot learning and simulation tools, such as LeRobot and MuJoCo, and keep you free to use your own robot.

Brand-neutral

Your robot, your code

We generate the native program for the cobot you already own, so your team is never locked in.
