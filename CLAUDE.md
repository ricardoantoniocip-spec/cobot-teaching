# Cobot teaching

Startup by Ricardo Cipriano (production engineer, Eindhoven; Portuguese and South African). Part time for now, solo, co-founder (ML / computer vision) later.

## What we build
Software that turns an operator's demonstration (camera, handheld tool or glove) into a working, verified cobot program. Goal metric: hours to deploy a new task, from days to under one.

## Decisions so far
- 2026-10-25: cobot teaching by demonstration is the single idea. The automation scout is not a product; it survives as a sales opener ("which task should a cobot learn first?").
- Customers: system integrators and high-mix manufacturing SMEs. First task type: kitting and pick-and-place, then machine tending.
- Markets: Portugal for first users and pilots, Netherlands for funding and co-founder, South Africa later via contacts, US after proof.
- Start now: sell a fixed-price "new task in a week" deployment service, build the workflow around open models (LeRobot), fund with grants and revenue first.
- Demo hardware: SO-101 arm, later PAROL6, then a real cobot.
